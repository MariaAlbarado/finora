# AlbarFin - Controle Financeiro

## Sobre o projeto

O AlbarFin é uma aplicação web de controle financeiro pessoal,
desenvolvida com o objetivo de facilitar o gerenciamento de
receitas, despesas e saldos de forma simples, intuitiva e organizada.

O projeto está em desenvolvimento e terá uma arquitetura Full Stack,
com integração entre front-end, back-end e banco de dados.

## Status do projeto

Em desenvolvimento.

Atualmente, o projeto conta com a interface visual da tela de login,
com layout responsivo e identidade visual própria.

## Funcionalidades

## Como executar o projeto

Instale as dependências:

npm install

Execute a aplicação:

npm run dev
